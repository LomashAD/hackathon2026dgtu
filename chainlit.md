# Помощник по документообороту

Чат-бот по **Инструкции по документационному обеспечению управления и документообороту** Организации.

- отвечает на вопросы со ссылками на пункты и процентом релевантности;
- подсказывает, с кем согласовать документ (Матрица обязательного визирования) и сроки;
- готовит черновики приказов и распоряжений по модулям документов (.docx);
- проверяет загруженный черновик на соответствие требованиям.

Работает полностью локально: модель Ollama, база знаний Chroma, без внешних API.
Роль пользователя выбирается в списке профилей вверху (в продакшне — из SSO).

Подключение к порталу

Окно справа внизу — Chainlit Copilot из установленного Chainlit (/copilot/index.js). Он работает с адреса помощника и использует вход сотрудника (cookie), поэтому страница должна открываться с того же адреса, что и чат.

<script src="https://<адрес помощника>/copilot/index.js"></script>
<script>
  window.mountChainlitWidget({ chainlitServer: "https://<адрес помощника>", theme: "dark",
    customCssUrl: "https://<адрес помощника>/public/widget/copilot.css",
    button: { imageUrl: "https://<адрес помощника>/public/favicon.svg" } });
</script>

Для портала на другом адресе надёжнее виджет в iframe одной строкой — <script src="…/widget.js" defer></script>: Copilot с чужого адреса требует открыть помощнику CORS и вход по токену (см. docs/frontend_notes.md).

# Интерфейс

Два варианта одного и того же чата:

1. **Отдельный веб-интерфейс** — `/?chat` (Chainlit): на стенде https://217-144-184-227.sslip.io/?chat, локально http://localhost:8000/?chat. Приветствие короткое — роль и подсказка: что умеет помощник, показывает команда `/help` (также «помощь», «что ты умеешь»).
2. **Поп-ап виджет для портала** — макет страницы портала на корневом адресе (https://217-144-184-227.sslip.io, локально http://localhost:8000): плавающая кнопка в правом нижнем углу открывает окно чата (iframe). Esc или × закрывает окно. Вкладки макета рабочие (адреса `#news`, `#docs`, `#services`, `#dou`, работает «назад»): «Новости» — лента новостей (ведётся в админ-панели) и автоматические новости о новых редакциях документов (`/api/news`), «Документы» берёт список из базы знаний (`/api/kb/documents`, `/api/templates`) и даёт скачать оригиналы, «Сервисы» показывает статус системы (`/api/health`), частые вопросы и кнопки-вопросы в новостях отвечают через `POST /api/ask`: в карточке видны первые 5 строк ответа, «Подробнее» открывает весь ответ в окне 650×500 по центру страницы (Esc или клик мимо окна закрывает). Тема по умолчанию как в системе; кнопка в правом верхнем углу портала и такая же в шапке чата (солнце — светлая, полумесяц — тёмная) переключают тему сразу и на портале, и в чате: выбор хранится в браузере под общим ключом (`public/theme.js`).

3. **Виджет для настоящего портала** — одна строка на любой странице портала: `<script src="https://<помощник>/widget.js" defer></script>`. Кнопка и окно рисуются в Shadow DOM (стили портала их не ломают), чат — тот же `/?chat` в iframe с входом сотрудника. Адрес портала вносится в `portal.embed_origins`; в продакшне вход — через SSO портала.

Все скриншоты получены автоматически скриптом `tests/ui_demo.py` в Chrome.

## Элементы интерфейса

| Элемент | Назначение |
|---|---|
| Вход (`/login`) и меню пользователя | Роль — из учётной записи (Сотрудник / Администратор), выбора роли в интерфейсе нет. В шапке портала — имя (клик — «Мой профиль» и смена своего пароля), «Выйти» и переключатель темы |
| «Админ-панель» (только администратор) | Разделы: Пользователи · Журнал действий · Вопросы без ответа и оценки · Новости · База знаний и статус (адреса `#admin/users`, `#admin/log`, `#admin/questions`, `#admin/news`, `#admin/kb`). В «Базе знаний»: новая редакция, «Добавить документ», «Отключить», «Сделать действующей» |
| «Документы» на портале | Действующие редакции и модули. Оригинал документа с пунктами ограниченного доступа роли без этого доступа не выдаётся: вместо «Скачать» — «🔒 оригинал — у администратора» |
| Ответ | Цитата пункта → «Простыми словами» → «См. также» → **Источники** с документом, редакцией, датой, пунктом, главой и **процентом релевантности** |
| Кнопка «📄 Тексты пунктов» | Полные тексты всех источников ответа |
| Кнопки быстрых ответов | Варианты уточняющего вопроса (вид документа, категория по Матрице, шаблон, да/нет, «оставить по умолчанию») |
| «Использовано: Поиск по базе знаний» | Раскрываемый шаг: намерение и число источников |
| Скрепка / drag&drop | Загрузка черновика .docx/.pdf на проверку |
| Карточка .docx | Скачивание сформированного черновика |
| 👍 / 👎 | Обратная связь (`storage/logs/feedback.jsonl`) |
| ⏱ | Время ответа |
| Настройки (только Администратор) | Поиск также в архивных редакциях |

## Макет виджета (схема)

```
┌──────────────── Внутренний портал Организации ────────────────┐
│  Новости · Документы · Сервисы · Раздел ДОУ · Админ-панель*   │
│                               Иванов И. И. · Выйти · ☀        │
│  ┌ Раздел Департамента ДОУ ──────┐  ┌ Частые вопросы ┐        │
│  │ Инструкция … (ред. 1.0)       │  │ …              │        │
│  └───────────────────────────────┘  └────────────────┘        │
│                                      ┌ Помощник по ДО ──── × ┐│
│                                      │ ✎      О помощнике ☀ ◉││
│                                      │ …диалог…              ││
│                                      │ [Задайте вопрос…] 📎 ➤││
│                                      └───────────────────────┘│
│                                  [Спросить про документооборот] (💬) │
└───────────────────────────────────────────────────────────────┘
* «Админ-панель» видна только администратору
```

Окно виджета — 520×640 px. На мобильной ширине окно виджета растягивается на всю ширину экрана с отступами 8 px.
